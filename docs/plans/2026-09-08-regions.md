# Regions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A dataset member can be one of several tables stacked in a text file or a sheet, named by ordinal (`report.csv#2`, `book.xlsx#Q1#2`), discovered by blank-row splitting, and gated behind review unless the split found exactly one block.

**Architecture:** `MemberRef` gains a third field, `region: Option<u32>`; sidecars and lock members carry it; a `RowWindow` on `Extraction::Delimited` (and the existing `range` on `Excel`) is what a region member's spec reads. `engine::regions_of` splits a file at runs of blank rows; `report::expand_units` asks it after sheets and expands several blocks into region members each carrying a review reason; `draft` splits the same way. Everything downstream (`dataset()`, report, `--accept`, `.accept`, `exclude`, `validate`, `check`, the workbench) reads the third field beside the second.

**Tech Stack:** Rust ≥ 1.88, the existing csv/calamine extractors, no new dependencies. Fixtures via a stdlib+openpyxl generator.

**Spec:** `docs/design/2026-09-08-regions.md` (decisions), on `docs/design/2026-09-06-members-and-regions.md` (the question) and `docs/design/2026-09-07-workbook-members.md` (the sheet half, whose shape this follows).

## Global Constraints

- `cargo test --workspace --lib --tests` stays green after every task; CI runs `cargo clippy --all-targets -- -D warnings` (not installed locally): no unused imports, no manual char comparisons, no redundant closures, use `is_multiple_of` over `% n == 0`.
- **tdy never silently produces a wrong value.** A region member is read from its sidecar's window; `dataset()` never splits a file itself. A window past the file's end is an error naming the line, never an empty table.
- **The review line:** several blocks → every region member carries `review` and waits for `--accept`; exactly one proper block → a plain member with a note and no review; the whole file as one block → unchanged behaviour.
- Plain and sheet members keep `region = None` and their existing sidecar names; existing locks, sidecars and fixtures keep their meaning. Every existing test keeps passing unchanged unless a task says otherwise.
- Stacked blocks only: the split is one-dimensional. Lines, fixed-width and JSON sources have no regions.
- Commit messages end with the trailer line `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Fixture facts (Task 4 makes them): `regions_three.csv` = three blocks of `Datum;Region;Betrag`, rows 3/3/3, sums 600.00 / 1500.00 / 900.00, one blank line between blocks; `regions_three.xlsx` = the same three blocks on sheet `Data` with one blank row between; `regions_summary.csv` = block 1 as above (600.00), a blank line, then a block headed `Region;Total` with 3 rows; `regions_titled.csv` = two title lines, a blank line, then one block (600.00).

```rust
pub struct MemberRef {
    pub path: String,
    pub sheet: Option<String>,
    /// One of several tables stacked in the file or sheet, counted from 1
    /// in file order. `None` is the whole file or sheet.
    pub region: Option<u32>,
}

impl MemberRef {
    pub fn file(path: impl Into<String>) -> MemberRef { MemberRef { path: path.into(), sheet: None, region: None } }
    pub fn sheet(path: impl Into<String>, sheet: impl Into<String>) -> MemberRef {
        MemberRef { path: path.into(), sheet: Some(sheet.into()), region: None }
    }
    pub fn region(path: impl Into<String>, sheet: Option<String>, region: u32) -> MemberRef {
        MemberRef { path: path.into(), sheet, region: Some(region) }
    }
    pub fn name(&self) -> String {
        let mut s = self.path.clone();
        if let Some(sh) = &self.sheet { s.push('#'); s.push_str(sh); }
        if let Some(r) = self.region { s.push('#'); s.push_str(&r.to_string()); }
        s
    }
    pub fn resolve(text: &str, exists: impl Fn(&MemberRef) -> bool) -> Result<Option<MemberRef>, Vec<MemberRef>> {
        let mut found: Vec<MemberRef> = Vec::new();
        let mut consider = |m: MemberRef| { if exists(&m) && !found.contains(&m) { found.push(m); } };
        consider(MemberRef::file(text));
        for (i, _) in text.rmatch_indices('#') {
            let (head, tail) = (&text[..i], &text[i + 1..]);
            consider(MemberRef::sheet(head, tail));
            if let Ok(n) = tail.parse::<u32>() {
                if n >= 1 {
                    consider(MemberRef::region(head, None, n));
                    for (j, _) in head.rmatch_indices('#') {
                        consider(MemberRef::region(&head[..j], Some(head[j + 1..].to_string()), n));
                    }
                }
            }
        }
        match found.len() { 0 => Ok(None), 1 => Ok(found.pop()), _ => Err(found) }
    }
}
```
